# Town of Denton — Autonomous Municipal Zoning

## 1. Regulatory Authority
- **Jurisdiction Type:** Autonomous Municipal Corporation (Md. Code Ann., Land Use Division I).
- **Zoning Authority:** Independent planning commission, board of zoning appeals, and municipal zoning code.
- **County Preemption:** County zoning ordinance does NOT apply within the incorporated corporate limits of this municipality.

## 2. Primary Sourcing
- **Official Portal:** Primary municipal clerk records, town code, and council meeting minutes.
- **GIS Parcels:** Coordinated with Caroline County GIS and municipal spatial mapping.
