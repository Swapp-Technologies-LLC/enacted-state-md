# Montgomery County, Maryland — Zoning Legal Repository

## 1. Regulatory Authority
- **Governing Body:** Montgomery County Council (sitting as the District Council for the Maryland-Washington Regional District).
- **Primary Ordinance:** Montgomery County Code **Chapter 59 (Zoning)**.
- **Planning Agency:** Montgomery Planning (M-NCPPC - Maryland-National Capital Park and Planning Commission).

## 2. Sourcing Architecture
- **Real-Time Change Stream:** Official Socrata API (`data.montgomerycountymd.gov/resource/3hex-pk9g.json`).
- **Enacted Amendment Archive:** `./zta_amendments/` (Zoning Text Amendments 2014–Present).
- **GIS Parcel Layer:** Montgomery County Planning Data Catalog (`data-mcplanning.hub.arcgis.com`) & Zoning Atlas (`mcatlas.org/zoning`).

## 3. Municipal Subdivisions & Independent Zoning Powers
- **`rockville/`**: Independent planning and zoning authority under City of Rockville Code Chapter 25.
- **`gaithersburg/`**: Independent planning and zoning authority under City of Gaithersburg Code Chapter 24.
- **`poolesville/`, `barnesville/`, `laytonsville/`**: Incorporated towns with independent zoning boards.
- **`chevy_chase/`, `kensington/`, `takoma_park/`**: Incorporated municipalities operating under County Chapter 59 with local overlay/historic district guidelines.
